# 恋普請 〜城下町と四つの花〜

ひょんなことから殿に領地を賜った若い侍が、四人のヒロインを秘書にして川のほとりの荒れ地に城下町を築く、街づくりと恋愛のシミュレーションです。
道を引き、品物を運ばせ、町人を働かせて天守を築きながら、ヒロインとの恋を進めます。HTML 1ファイルで動き、ビルドは要りません。

（旧タイトル「城下町普請帖」の街づくり部分はそのまま入っています）

## はじまり

1. 「画面をタップしてください」でタップすると、フラッシュのように画面が白く光り、大豆が転がってきて「だいずソフト」のロゴが出る
2. タイトル「恋普請」→ ヒロイン四人 → 主人公・殿・帝 → 町の人々 → 闇武将・闇武者・山賊・夜盗 → 戦いの場面 → 町をズームアウトして、もう一度タイトル
3. オープニングの途中で画面をタッチすると、すぐタイトル画面へ
4. タイトル画面ではトンビが「ピーヒョロロ」と鳴きながら空を横切る。始めると金色の雲（金雲）が閉じてから左右に開き、トンビの声とともに町づくりが始まる

## ヒロイン

| 名前 | タイプ | 得意（秘書にすると町全体に効く） | 能力（武・技・知・魅） |
|---|---|---|---|
| 小春 | 元気なおてんば娘（棟梁の娘） | 突貫普請：普請の速さ・人の歩く速さが上がる | 4・5・2・4 |
| 雪乃 | クールな眼鏡の勘定方（家老の姪） | 算盤勘定：問屋の売値・年貢が上がる | 2・3・6・3 |
| 千鶴 | 面倒見のいいお姉さん（茶屋の女将） | 町の姐さん：満足度・移り住む人が増え、食べる量が減る | 2・3・4・6 |
| 楓 | 無口なくノ一（闇武将の元配下） | 影働き：災いへの対処力が上がり、被害が減る | 7・3・3・3 |

- 秘書はいつでも替えられる。見た目でも性能でも選べ、恋のルートとは関係しない
- 楓は領主レベル5で、闇武者の襲撃から町を救って仲間になる
- 好感度は「話す」（1日1回）、贈り物（好物は大きく上がる）、秘書として毎日一緒に働く、災いを一緒に退けることで上がる。好感度が上がるほど得意の効果も上がる
- 好感度が一定に達すると「特別な話」（選択肢つき）が見られる。秘書の顔に「!」が出たら話しかける

### ルートの決まり方

**共通ルート → 中盤の選択で個別ルート**の形にしています。

- 序盤〜中盤は四人全員と話して仲良くなれる（好感度は「気になる人」まで）
- 第四章を終えると城下で初めての夏祭り。誰と回るかを選ぶと、その子のルートに入る
- ルートに入った子だけ「想い人」「恋人」まで仲が深まり、ルート専用の話が二つ進む
- 天守を築き、ルートの話を最後まで見るとエンディング。見たエンディングは「思い出帖」に残り、新しく始めれば別の子のルートも見られる

## 招集（ガチャ）

小判や招き札を使って町人・職人・武士を招きます（全28人）。

- ★3は4%、★2は24%、★1は72%。10回招くと★2以上が1人確定。50回で★3確定
- 同じ人が来ると「重ね」になり、効果が20%ずつ上がる（5重ねまで。それ以上は小判に替わる）
- 町人は満足度・年貢・移住、職人は品物ごとの生産や普請の速さ、武士は災いへの対処力を上げる。効果は町全体にずっと効く
- 一人ひとりに武・技・知があり、災いのときは部隊として戦う
- 最初に招き札10枚ぶんを無料で招ける

## 領主レベルと災い

建物の完成、毎日の暮らし、章の達成、災いの対処、献上で経験値がたまり、レベルが上がると小判がもらえ、起こる出来事が増えます。

|---|---|---|
| 2 | 獣害（猪が田畑を荒らす） | 武 |
| 3 | 殿の謁見（問いに答えて褒美） | — |
| 4 | 虫害（イナゴの大群） | 知 |
| 5 | 闇武者の襲来（楓との出会い） | 武 |
| 6 | 山賊 | 武 |
| 7 | 火事 | 技 |
| 8 | 夜盗 | 知 |
| 9 | 洪水 | 技 |
| 10 | 地震 | 技 |
| 12 | 朝廷の使者（帝への献上が解禁） | — |
| 14 | 闇武将・黒鉄玄蕃の襲来（倒すたびに強くなる） | 武 |

- 災いが起きると左上に知らせが出る。秘書と集めた人から3人を選んで出陣し、勝算に応じて勝ち負けが決まる（戦いの演出つき）
- 負けたり翌朝まで放っておくと、建物が数日止まる・お金や品を奪われる・材木が燃えるなどの被害が出る
- 立ち向かう力に合わせて秘書を替えるのがこつ（知の災いなら雪乃、武なら楓など）

## 特産品と献上

- 品物をたくさん作るほど特産品が生まれ、並→上→極と格が上がる（新米「青葉錦」、銘酒「城下の月」、いぶし銀の瓦 など7種）
- いちばん名高い品が「町の特産」になり、献上すると褒美が1.5倍
- 殿へは3日に1度（小判・両・殿の覚え＝年貢の上乗せ）、帝へは5日に1度（小判・招き札・帝の覚え＝満足度の上乗せ）

## ログインボーナス

毎日ひらくと7日でひとめぐり（小判、両、招き札、材木と石など）。7日目は招き札3枚。

## 見た目

- ヒロイン4人は、アニメ調のバストアップのイラスト（SVGで描画）。人気のアニメやゲームのキャラクターデザインで言われる要点を取り入れている
  - 遠目にも誰かわかるシルエットと小物（小春のサイドポニーと赤いリボンとアホ毛、雪乃の姫カットと眼鏡、千鶴のウェーブのロングとかんざし、楓の銀髪と額当てと覆面）
  - 一人ひとりのテーマカラー（小春は朱、雪乃は藍、千鶴は紫、楓は墨色と紅）と、着物の柄（矢絣、麻の葉、桜、亀甲）
  - 大きな目：瞳は上が暗く下が明るいグラデーション、主なハイライトをひとつ、目尻側を濃くしたまつげ。つり目・たれ目で性格を出す
  - 毛束で描いた髪と、光の帯（天使の輪）、毛先に向かって濃くなる影
- 立ち絵はまばたきし、ゆっくり呼吸し、セリフの文字が出ている間は口が動く
- 表情：ふつう・笑顔・照れ・怒り・悲しみ（涙）・驚き。楓は仲が深まると覆面を外す
- 主人公・殿・帝・闇武将・闇武者・山賊・夜盗・町人・職人・武士は、ちびキャラのドット絵（50×60ドット）
- 町は three.js（r128、cdnjs から読み込み）による2.5Dのクォータービュー。読み込めないときは2Dの絵図表示に切り替わる

## 音

- 効果音と環境音は、インターネットで公開されている録音素材（ほとんどが CC0＝パブリックドメイン）を短く切って、HTMLの中に埋め込んでいる（合計およそ0.9MB）
- 町の環境音は季節と時刻で変わる：春と秋の昼は日本庭園（兼六園）の音、夏の昼はセミ、冬は風、夜は虫の声。夏祭りの場面では祭りのざわめき
- 寺の鐘（京都・大徳寺の録音）、太鼓、鼓、琴、三味線、尺八、拍子木、半鐘、刀を振る音と打ち合う音、金づち、小判、ふすま、風鈴など
- 災いごとに音が変わる（猪、虫の羽音、馬のひづめ、火、濁流、地鳴り）
- タイトルと雲が開く場面の鳥の声は、アカオノスリ（タカの仲間）の鳴き声の録音
- 「その他」から効果音と環境音をそれぞれオン・オフできる

## 街づくり（もとからの遊び）

- **普請（建設）は物流で進む**：建物を置くと普請場になり、蔵の人足が材料を運び、普請小屋の大工が組み上げる
- **道がすべて**：人も荷も道しか通れない。川には橋を架けられる
- **町人は通勤する**：朝に長屋を出て仕事場へ歩き、夕方に帰る
- **生産のつながり**：原木 → 材木、粘土＋原木 → 瓦、米 → 酒
- **季節**：田んぼは秋によく実り、冬は休む
- **満足度**：食事、米と魚、酒、湯屋、寺社、城、秘書や集めた人の力で上がる

## 操作

- 1本指でドラッグ：地図を動かす／2本指でつまむ：拡大・縮小（パソコンではマウスホイール）
- 右上の ⟲ ⟳：視点を90度ずつ回す
- 下の指示：道・建てる・撤去・帳簿・招集・献上・その他（秘書、思い出帖、図鑑、領主レベル、ログインボーナス、遊び方、設定）
- 左下の秘書をタップ：話す・贈り物・秘書を替える

## 起動方法

- `index.html` をブラウザで開くだけで遊べます
- 町は1日ごとと建物を建てたときに、そのブラウザの localStorage に自動保存されます。見たエンディングとログインボーナスの記録は別に保存され、新しく始めても残ります
- 以前の「城下町普請帖」のセーブデータも読み込めます（読み込むと秘書選びから始まります）

## 動作確認

ブラウザの自動操作で、オープニング→タイトル→プロローグ→秘書選び→招集→町、災いと戦闘、献上、謁見、特別な話、夏祭りのルート選択、エンディング、ログインボーナス、保存と読み込み、すべての音の読み込みと再生を確かめています。自動で町を作って50日以上進めるテストで、レベルの上がり方・災いの勝率・特産品の格の上がり方を調整しています。
