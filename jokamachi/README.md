# 城下町普請帖

江戸時代、殿の命を受けた普請奉行となって、川のほとりの荒れ地に城下町を築く街づくりシミュレーションです。
道を引き、品物を運ばせ、町人を働かせて、最後は天守を築きます。HTML 1ファイルで動き、ライブラリもビルドも要りません。

## どんなゲームか

自分で指示を出して町を動かす、物流と人の動きを重視した街づくりです。

- **普請（建設）は物流で進む**：建物を置いても、その場は普請場になるだけです。蔵の人足が材料（材木・石・瓦）を運び込み、普請小屋の大工が組み上げて完成します
- **道がすべて**：人も荷も道しか通れません。建物は道に接していないと動きません。川には橋を架けられます
- **町人は通勤する**：朝に長屋を出て仕事場へ歩き、夕方に帰ります。住まいと仕事場が遠いと働く時間が減ります
- **生産のつながり**：原木 → 材木（製材所）、粘土＋原木 → 瓦（瓦窯）、米 → 酒（酒蔵）
- **季節**：田んぼは秋によく実り、冬は休みます。秋のうちに米をたくわえないと冬に飢えます
- **食べ物の配り先**：長屋は市（9マス）か蔵（6マス）の範囲にないと食べ物が届きません
- **満足度**：食事、米と魚の両方、酒、湯屋、寺社、城の進み具合で上がります。高いほど人が集まり、よく働きます

## 自分で出せる指示

| 指示 | 内容 |
|---|---|
| 道を引く | 始まりと終わりのマスをタップ（まっすぐかL字）。川の上は橋になる |
| 建てる・撤去 | 普請場を置く、取りこわす |
| 優先度 | 建物ごとに 低・普通・高・停止。働き手の割り振りと荷運びの順番が変わる |
| 市の品ぞろえ | 米・魚・酒を並べるかどうか |
| 問屋の売り買い | 品物ごとに「売る（蔵に残す数を指定）」「買う（1日あたりの数）」 |
| 時の速さ | 止める・ふつう・はやい・とてもはやい |

登場人物：家老・佐伯、棟梁・源兵衛、村年寄・しの、殿・青葉守（すべて架空）

## 操作

- 1本指でドラッグ：地図を動かす
- 2本指でつまむ：拡大・縮小（パソコンではマウスホイール）
- 建物をタップ：状態・在庫・指示の画面
- 「帳簿」：すべての蔵の在庫、昨日の生産と消費、人口と仕事、人足の忙しさ

## 起動方法

- `index.html` をブラウザで開くだけで遊べます
- 町は1日ごとと建物を建てたときに、そのブラウザの localStorage に自動保存されます

## 動作確認

自動で町を作って時間を進めるテストで、物流・建設・通勤・食料・季節・税・物語の進行・築城の3段階が最後まで動くことを確かめています。人足が足りないと品物が作り場にたまって止まるため、蔵を増やして人足を確保するのがこつです。
