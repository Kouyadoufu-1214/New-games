# ハコニワブロック

ブロックを置いて縦か横の列をそろえて消し、集めた★で自分だけの浮き島（箱庭）を育てるスマホ向けパズルゲームです。
HTML 1ファイルで動きます。ライブラリもビルドも要りません。

## 遊び方

1. 下に並んだ3つのブロックを盤面（8×8）へドラッグして置く
2. 縦か横を1列うめると消える。続けて消すとコンボで点数アップ（3手続けて消せないと途切れる）
3. 芽のついたブロックを消すと★がもらえる。★で島に建物を建てると、次から★が増える

時間制限はありません。置ける場所がなくなったら終わりです。

## 起動方法

- `index.html` をブラウザで開くだけで遊べます
- スマホで遊ぶ場合は、GitHub Pages などで公開してスマホのブラウザで開き、「ホーム画面に追加」するとアプリのように全画面で遊べます
- 記録（★、島、ベストスコア、途中のゲーム）はその端末のブラウザ（localStorage）に保存されます

## 機能

| 機能 | 内容 |
|---|---|
| フリープレイ | 時間制限なしで遊び続けるモード。スコアが上がるほど大きいブロックが出やすくなる |
| 今日のチャレンジ | 日付ごとに全員が同じ30ピースで遊ぶスコアアタック。結果を絵文字つきテキストでコピーしてSNSに貼れる |
| 島づくり | ★で16種類の建物を順番に建てる。1つ建てるごとに獲得★が +3% |
| 今日のミッション | 毎日3つ入れかわる目標（例：ラインを25本消す）。達成で★、3つ全部で追加ボーナス |
| 連続ログイン | 毎日の初回起動で★。7日目まで連続日数に応じて増える |
| おたすけ | 詰んだときに1ゲーム1回だけ、いちばん詰まった縦横4列を片づけて続けられる（1日1回は無料、以降は★15） |
| 続きから | 途中でアプリを閉じても、次に開くと続きから遊べる |

ほかに、指で隠れないようにブロックを指の少し上に表示する、消える列を置く前に光らせる、効果音とバイブ、ダークモード（夜の島）に対応しています。

## 研究からの設計

2026年11月時点の人気スマホゲームの調査（世界の売上・DL上位、日本の上半期ランキング）で見えた「流行る理由」を、1本の小さなゲームに組み込みました。

| 調査で見えた流行る理由 | 代表作 | このゲームでの取り入れ方 |
|---|---|---|
| 3秒で遊び方がわかり、焦らされない | ブロックブラスト（2026年1〜3月の世界DL数1位） | 8×8の盤にブロックを置くだけ。時間制限なし |
| 入り口は軽く、奥は深い | ラストウォー、ドラクエ スマッシュグロウ | 簡単なパズルの外側に、島づくりという長期目標を用意 |
| 毎日やることがある（イベントを途切れさせない） | MONOPOLY GO!、Royal Match、Gossip Harbor | 毎日入れかわるミッション、連続ログイン、今日のチャレンジ |
| 損をしたくない気持ち・あと少しの気持ち | Royal Match のイベント設計 | コンボの残り手数表示、詰んだときの「おたすけ」 |
| 短い動画やSNSで面白さが伝わる | ブロックブラスト（TikTok）、Roblox | 連続消しの派手な演出、チャレンジ結果の共有テキスト |
| 全員が同じ条件で競える | 日替わりパズル系 | 今日のチャレンジは日付をシードに全員同じピース順 |

一方で、調査で批判が多かった点は取り入れていません。

- 広告と中身が違う「誇大広告」：広告はなく、遊べる内容そのままです
- 課金・ガチャ：ありません。★はゲーム内で集めるだけです
- 強いプレッシャー：時間制限や対戦はなく、ミッションを逃しても何も失いません
