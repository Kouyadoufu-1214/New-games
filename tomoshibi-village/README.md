# ともしびの村

昼は村を育て、夜は影から灯を守る、街づくり×サバイバルのスマホ向けシミュレーションゲームです。
HTML 1ファイルで動きます。ライブラリもビルドも要りません。

## 遊び方

- **昼（時間制限なし）**：大灯籠の光が届くマスに建物を建てる。木・石・食料は毎朝まとめて手に入る
- **夜**：影が大灯籠をめざしてまっすぐ進んでくる。柵でふさぎ、見張り塔や投石台で倒す。影を直接タップしても攻撃できる。スキル「ひかりの波」「応急修理」も使える
- **住民と食料**：畑・木こり小屋・塔などは住民が1人いないと動かない。住民は毎日1つ食料を食べる。家を建てると毎朝新しい住民がやってくる
- 大灯籠が消えたら負け。ただし、その日の朝からやり直せる

## 建物

| 建物 | 解放 | 内容 |
|---|---|---|
| 🏮 大灯籠 | 最初から | 村の中心。強化すると光が広がり、建てられる場所・住める人数・建物の最大レベルが増える（Lv8まで） |
| 🛖 家 | Lv1 | 住める人数が増える |
| 🌱 畑 | Lv1 | 毎朝、食料 |
| 🪓 木こり小屋 | Lv1 | 森のマスに建てる。毎朝、木 |
| ⛏️ 石切り場 | Lv1 | 岩場のマスに建てる。毎朝、石 |
| 🚧 柵 | Lv1 | 影の通り道をふさぐ。強化で石の壁・鉄の壁に |
| 🏹 見張り塔 | Lv1 | 近くの影を矢で射る |
| ☄️ 投石台 | 大灯籠Lv3 | まとまった影をまとめて倒す |
| 🔥 かがり火 | 大灯籠Lv4 | 近づいた影を遅くして焼き、まわりを照らす |

どの建物も3段階まで強化できます。住民は 畑 → 木こり小屋 → 石切り場 → 見張り塔 → 投石台 の順に仕事につきます。

## 起動方法

- `index.html` をブラウザで開くだけで遊べます
- スマホで遊ぶ場合は、GitHub Pages などで公開してスマホのブラウザで開き、「ホーム画面に追加」すると全画面で遊べます
- 村は昼のあいだ自動で保存されます（その端末のブラウザの localStorage）。夜の途中で閉じると、その日の夕方から再開します

## 研究からの設計

人気スマホゲームの調査（2026年11月時点）で見えた「流行る理由」を、街づくり・サバイバルの形に組み込みました。

| 調査で見えたこと | 代表作 | このゲームでの取り入れ方 |
|---|---|---|
| 売上が伸びている唯一のジャンルが戦略・街づくり | ラストウォー、Whiteout Survival | 拠点を育てて資源を回し、外敵から守る基本の流れ |
| 簡単なアクションと奥深い街づくりの組み合わせ（ハイブリッド） | ラストウォー | 夜は影をタップして倒す手軽なアクション、昼はじっくり街づくり |
| 中心の建物のレベルがすべてを広げる | 4X系の定番 | 大灯籠の強化で光の範囲・建てられる建物・強化上限が広がる |
| 迷わせない目標の連続 | 4X系の定番 | 画面上部の「目標」が次にやることを教え、達成で報酬 |
| 毎日の小さなできごと・選択 | イベント運営型の人気作 | 朝ごとに旅の家族・行商人・濃い霧などのできごとが起き、選択で結果が変わる |
| 毎日開く理由 | 連続ログイン系 | 1日1回の「今日の補給」 |
| どこまで行けるかの挑戦 | ローグライト系 | 生き延びた日数の最高記録 |

一方で、調査で批判が多かった点は取り入れていません。

- 広告と中身が違う「誇大広告」：広告はなく、遊べる内容そのままです
- 課金・ガチャ：ありません
- 強いプレッシャー：昼には時間制限がなく、負けても朝からやり直せます

## 難易度

自動プレイで確かめた目安です（人の判断のほうが上手なので、実際はもう少し先まで進めます）。

- スキルやタップを使わず放っておく：5〜7日目あたりで負ける
- スキルとタップを使う：12〜14日目あたりまで
- 7日目、14日目、21日目…はボス「夜の主」が来る
